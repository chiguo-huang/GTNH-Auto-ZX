# Starry Fall Automation ⭐

> GTNH（GregTech: New Horizons）**血魔法陨星仪式自动化**控制脚本，运行在游戏内 **OpenComputers** 电脑上。
>
> 你只需要补充祭品、维持 LP，剩下的全自动：召唤陨石 → 采集矿石 → 清理场地 → 无限循环。

## 🚀 快速开始

OC 电脑插入**互联网卡**，在终端执行：

```
wget https://gitee.com/mika-miko/starry-fall-automation/raw/master/zx.lua zx.lua
```

红石输出测试工具（可选，排查信号用）：

```
wget https://gitee.com/mika-miko/starry-fall-automation/raw/master/redstone_test.lua redstone_test.lua
```

更新脚本：重新执行同一条命令覆盖即可。

装置搭建见下文 → 运行 `zx.lua` → 按提示选模式、答方向 → 开始挂机。

## 🔄 工作流程

```
① 读取祭品抽屉 2 号槽          没有祭品 → 待机，每 10 秒重查
        ↓
② 白名单 + 模式过滤            不合格 → 整堆丢进垃圾箱
        ↓
③ 等宝珠就位、LP 攒够          LP 差 100 以内即开跑
        ↓
④ 移 1 个祭品 → 末影箱 1 号槽（喂给仪式）
   红石触发仪式 → 等 11 秒陨石落地
        ↓
⑤ 按祭品类型处理陨石：
   ├ type 3 纯矿石 → 采矿场采集
   ├ type 2 混合   → 采矿场采集 → 清理机扫尾
   └ type 1 无矿石 → 清理机直接回收
        ↓
⑥ 回到 ①
```

## 🔌 连接总览

```
OC 电脑 ─红石(东)→ 陨星仪式主石       触发召唤（拉高 11 秒）
采矿场 ─红石(南)→ OC 电脑            "开采完成"信号（强度 15）
OC 电脑 ─红石(西)→ 清理机            启停（仅模式 1/2）
清理机 ─红石(北)→ OC 电脑            "清理完成"信号（仅模式 1/2）
OC 电脑 ─网络──→ 适配器 → GT 采矿场×N setWorkAllowed 软件启停（不走红石）

转运器（网络接入 OC 电脑），四个面分别贴：
  祭品抽屉（读 2 号槽） │ 末影箱（写 1 号槽）
  垃圾箱（收非白名单）  │ 迷你箱（放宝珠，读 LP）
```

## 🧱 硬件清单

- [ ] OC 电脑 ×1（插红石卡；下载时另需互联网卡，下完可拆）
- [ ] 转运器（transposer）×1 —— 四个面贴上述容器
- [ ] 适配器 ×1 —— 连接 GT 采矿场
- [ ] GT 采矿场（ore drilling plant）×N —— 数量任意，脚本自动发现
- [ ] 清理机 ×1（仅模式 1/2：奥术钻探机 或 填充机）
- [ ] 红石线若干

## ⚡ 红石接线

**只需 1 张红石卡**，但每路信号必须接电脑的**不同面**（方向为绝对方向，启动时逐个确认）：

| 方向(默认) | 通道 | 信号方向 | 电平 | 何时需要 |
|---|---|---|---|---|
| 东 e | `side_ritual` | 电脑 → 仪式 | 15 = 触发（11 秒） | 所有模式 |
| 南 s | `side_done_drills` | 采矿场 → 电脑 | 15 = 完成 | 所有模式 |
| 西 w | `side_miners` | 电脑 → 清理机 | 15 = 启动 | 模式 1/2 |
| 北 n | `side_done_miners` | 清理机 → 电脑 | 15 = 完成 | 模式 1/2 |

上 / 下两面空闲。**模式 3 只需 2 路红石，模式 1/2 需 4 路。**
全脚本只支持**一个** redstone 组件（多张红石卡或多个红石 I/O 方块混用会失效）。

## ⚙️ 三种模式

| 模式 | 清理机 | 接受的祭品 | 红石路数 |
|---|---|---|---|
| 1 奥术钻探机 | 奥术钻探机 | 白名单全部 | 4 |
| 2 填充机 | 填充机 | 排除无矿石（type 1） | 4 |
| 3 纯矿石（默认） | 无需 | 仅纯矿石（type 3） | 2 |

## 💎 祭品分类

白名单定义在 `zx.lua` 的 `itemData`（键为 `物品名:damage`），共三类：

| type | 陨石内容 | 示例祭品 | 落地处理 |
|---|---|---|---|
| 1 | 无矿石 | 西瓜、TNT、灵魂沙 | 清理机回收 |
| 2 | 矿石+杂质 | 末地石、河豚 | 采矿场 → 清理机 |
| 3 | 纯矿石 | 下界之星、太空采矿模块 | 采矿场 |

新增祭品：在 `itemData` 加一行，注明 `type` 与 `lp` 消耗。

## ⚠️ 注意事项

- **槽位是硬编码**：祭品读抽屉 2 号槽；喂仪式固定写末影箱 1 号槽
- **完成信号约定**：外部拉到强度 15 才算完成；超时 300 秒自动重试
- **启动需要人工**：选模式、答方向（回车用默认值），不是全自动开机
- **多采矿场**：按机器名 `multimachine.oredrill` 自动发现并批量控制，加减机器不用改代码
- **LP 容差**：差 100 以内即开跑（转运期间 LP 仍在增长）
- **红石排查**：怀疑信号发不出去时，用独立测试脚本 `redstone_test`：不带参数 = **6 个面同时输出强度 15 信号 15 秒**后全部归零（一次看清哪些面能出信号）；或 `redstone_test <up|down|east|west|north|south> [时长秒] [信号强度]` 单测某一面。启动时也会回显生效的方向配置，与布线核对即可
