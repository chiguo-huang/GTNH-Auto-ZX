# Starry Fall Automation

GTNH（GregTech: New Horizons）血魔法**陨星仪式（流星农场）全自动控制脚本**，运行在游戏内 OpenComputers 电脑上。

## 功能

- 自动读取抽屉中的祭品，按白名单（`itemData`）和所选模式过滤，不合格物品自动丢弃
- 自动检测灵魂网络 LP 储量（通过宝珠读取），攒够后自动发起陨星仪式
- 陨石落地后自动处理：
  - 纯矿石陨石 → GT 采矿场自动采集
  - 混合陨石 → 采矿场采矿石 + 清理机（奥术钻探机/填充机）扫尾
  - 无矿石陨石 → 清理机直接回收
- 全程循环运行，只需补充祭品和维持 LP 即可挂机

## 下载

在游戏内 OC 电脑的终端中执行（需要**互联网卡**）：

```
wget https://gitee.com/mika-miko/starry-fall-automation/raw/master/zx.lua zx.lua
```

更新脚本时重新执行同一条命令即可。

## 使用

1. 按下方硬件要求搭建装置并连好 OC 电脑
2. 运行 `zx.lua`，按提示选择模式（1 奥术钻探机 / 2 填充机 / 3 纯矿石，默认 3）并输入各方向
3. 往抽屉里放祭品，开始挂机

## 硬件要求

- OC 电脑 + 红石卡 + 转运器（transposer）
- 转运器需连通四个容器：祭品抽屉（读 2 号槽）、末影箱（喂仪式，写 1 号槽）、垃圾箱（任意普通箱子）、放宝珠的迷你箱
- 若干 GT 采矿场（ore drilling plant）；模式 1/2 另需清理机及其红石控制
- 具体布局约定见 [CLAUDE.md](CLAUDE.md)

## 红石布线

只需 **1 块红石卡**，但卡上的每个面都是独立的一路信号，各通道必须接在电脑的**不同面**上：

| 通道 | 作用（默认方向） | 类型 | 何时需要 |
|------|------------------|------|----------|
| `side_ritual` | 触发陨星仪式（s） | 输出 | 所有模式 |
| `side_done_drills` | 采矿场完成信号（w） | 输入 | 所有模式 |
| `side_miners` | 清理机启停（d） | 输出 | 仅模式 1/2 |
| `side_done_miners` | 清理机完成信号（u） | 输入 | 仅模式 1/2 |

- **模式 3 只需 2 路**（仪式输出 + 采矿场完成输入）；**模式 1/2 需要 4 路**
- 启动时脚本会逐个询问每路信号所在的方向（n/s/e/w/u/d，方向为绝对方向）
- 只支持一块红石卡：若存在多个 redstone 组件（多张卡或多个红石 I/O 方块），脚本只会使用最后检测到的一个

布线示例（模式 2）：

```
电脑南面 ──红石线──> 仪式主石（电脑输出，触发仪式）
电脑西面 <─红石线── 采矿场完成信号（电脑输入）
电脑下面 ──红石线──> 填充机/奥术钻探机（电脑输出，启停）
电脑上面 <─红石线── 清理机完成信号（电脑输入）
```

转运器不走红石，接在任意不冲突的面即可。
